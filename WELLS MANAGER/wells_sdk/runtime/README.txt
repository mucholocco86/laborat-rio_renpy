Wells SDK runtime inventory
===========================

Source: mucholocco86/laborat-rio_renpy, renpy-8.5.3-sdk, main tree
d0078e098f6ce597b9fef2a1e21096608c4dcdd9 (14 October 2026).

This directory contains the Windows x86_64 Ren'Py runtime files used by the
two Wells SDK operations. It keeps the engine package, the Python 3.12
runtime modules, the Windows engine libraries, the startup entry points, and
the upstream license.
The Ren'Py engine sources are not rewritten.

The package omits the Ren'Py launcher interface, documentation, tutorial and
sample projects, mobile and macOS/Linux distributions, updater executables,
the GUI project template, and historical research copies of translation
modules. It does not expose project execution, distribution building, SDK
updates, or other launcher actions in the Wells interface.

See LICENSE.txt for upstream notices. Check any component-specific notices
before changing or redistributing this runtime.
