Diretorio destinado a armazenar a estrutura de jogos
para testes das ferramentas e os SDK's armazenados no laboratorio,
estes arquivos armazenados neste diretorio são estruturas
de jogos reais contendo todos seus scripts de forma identica
ao arquivos fisicos, a unica coisa que o diretorio não contem
são arquivos como imagens, sons e fontes de textos,
pois para as ferramentas atualmente sendo desenvolvidas
esses arquivos deixados de fora são momentaneamente desnecessarios,
talvez sejam acrescentados quando ouver uma ferramenta que trabalhe
com imagens, sons etc, mas para os projetos atuais ainda não são arquivos
necessarios para o desenvolvimento.
